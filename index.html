2 Grayscale

Converted with linear intensity: gamma is decoded, Rec.709 weights are applied in linear light, then the result is re-encoded. 

gray = (0.2126·R^2.2
      + 0.7152·G^2.2
      + 0.0722·B^2.2) ^ (1/2.2)

No options in this version.

3 Tone

Negative contrast flattens, positive applies an S-curve. Brightness is a gamma curve that lifts or lowers the midtones, applied after contrast so the two stay independent. 0 and 255 are always preserved.

4 Dither & save

Copy the file into the /OFFIMG/ folder on the calculator's USB disk, then switch the unit off.
